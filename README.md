# CannonWars
CANNONWARS!!! (written in OpenFrameworks)


# Red Player(A)
use up and down arrows to move up and down, left and right to move left and right, use the keys ,(comma) and .(period) to move barrel, space to shoot 


# Blue Player(B)
use W and S arrows to move up and down, A and D to move left and right, keys Q and E to move barrel, F to shoot
